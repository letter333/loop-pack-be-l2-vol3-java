# 요구사항 분석

## 1. 회원 (Member)

### 1.1 회원가입

| 항목 | 내용 |
|------|------|
| **Actor** | 비회원 |
| **목적** | 새로운 계정을 생성하여 서비스를 이용한다 |

**비즈니스 규칙**

| 규칙 ID | 설명 | 위반 시 |
|---------|------|---------|
| MBR-001 | loginId는 중복될 수 없다 | 409 Conflict |
| MBR-002 | email은 중복될 수 없다 | 409 Conflict |
| MBR-003 | password는 영문 대/소문자, 숫자, 특수문자만 허용 | 400 Bad Request |
| MBR-004 | password에 생년월일(YYYYMMDD 형식) 포함 불가 | 400 Bad Request |
| MBR-005 | 모든 필수 항목은 빈 값일 수 없다 | 400 Bad Request |
